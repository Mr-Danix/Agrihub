# 🌱 AgriHub

**Live Website:** https://mr-danix.github.io/Agrihub/

AgriHub is a web platform designed to support farmers by connecting them with agricultural resources, services, and market opportunities in one place.

---

## 🚀 Features

- 🌾 Farmer-focused platform  
- 🛒 Marketplace for agricultural products  
- 🤝 Connect with experts and services  
- 📚 Access to farming information  
- 🌐 Multi-language support (English, Amharic, Afaan Oromo)

---

## 🎯 Purpose

AgriHub helps solve key agricultural challenges by:

- Improving access to information  
- Connecting farmers with experts  
- Providing a digital marketplace  
- Supporting better decision-making
